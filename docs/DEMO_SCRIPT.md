# MoneyFy hackathon demo

1. Open the existing website and show the rotating coin, tagline, white interface and left navigation.
2. Create an account. Explain that its empty database workspace is separate from the offline synthetic demo.
3. In Privacy Center, set balance, reserve, salary, balance date and payday; enable import consent. Use synthetic CSV or explicitly reset to sample data.
4. In Transactions upload a sample CSV and manually categorize an unknown merchant. Reload to demonstrate persistence.
5. Show Dashboard forecasts and their assumptions. Opening balance is a supplied snapshot, not a reconstructed bank ledger.
6. In Money Autopilot inspect evidence and confirm a proposed adjustment. No actual transfer occurs.
7. Change a What-If slider and compare the Python forecast. Show shared goal capacity, score components and alerts.
8. Show How It Works and privacy export/deletion. Financial deletion retains the login account.
9. Resize to a phone viewport to demonstrate touch navigation. Explain that Capacitor packaging is prepared but an APK has not been generated because Android SDK/JDK setup is missing.

Do not claim real bank access, trained AI, verified PostgreSQL deployment or device-tested native behavior. Keep demo accounts and statements synthetic.
